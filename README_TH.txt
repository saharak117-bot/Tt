เครื่องเล่นเพลง - วิธีใช้งาน

1. แตกไฟล์ ZIP
2. นำโฟลเดอร์ขึ้นเว็บโฮสติ้งที่รองรับ HTTPS (หรือเปิดผ่าน localhost เพื่อทดสอบ)
3. เปิด index.html ผ่านเว็บเซิร์ฟเวอร์ แล้วกด เพิ่มเพลง เพื่อเลือกไฟล์เสียงจากเครื่อง
4. ใช้ปุ่มสุ่ม และปุ่มวนซ้ำเพื่อเลือกโหมด ปิด / วนทั้งหมด / วนเพลงเดียว
5. ปรับ EQ 10 ย่าน, Bass, Treble, Presence, Preamp, Volume, Balance, Speed และ Bass Boost ได้ตามต้องการ
6. บน Android ให้เริ่มเล่นเพลงใน Chrome ก่อน จากนั้นสลับแอปหรือล็อกหน้าจอเพื่อทดสอบการเล่นเบื้องหลัง

ข้อจำกัดสำคัญ
- นี่คือ PWA ไม่ใช่แอป Android native ที่มี Foreground Service
- Chrome/Android มักให้เสียงเล่นต่อในเบื้องหลังเมื่อมี audio playback และ Media Session แต่ไม่มีการรับประกันในทุกเครื่อง/ทุกเบราว์เซอร์
- โหมด EQ ใช้ Web Audio API; การทำงานขณะล็อกหน้าจออาจต่างกันตามอุปกรณ์และระบบประหยัดพลังงาน
- ถ้าต้องการความแน่นอนระดับแอปเพลง Android ต้องทำแพ็กเกจ native พร้อม MediaSession/Foreground Service เพิ่ม
- ไฟล์เพลงอยู่ในเครื่องและไม่ได้ถูกอัปโหลด
